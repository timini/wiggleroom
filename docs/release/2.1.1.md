# WiggleRoom 2.1.1 release record

## Scope

ACID9 Voice only, GPL-3.0-or-later. Existing plugin/module slugs and parameter/port IDs are retained. Matter and all other modules are deferred. The new cosmic faceplate is 34HP (previous development panel: 20HP).

## Changes

- Precise, outlined functional labels over cosmic artwork, with illustrated module and Wiggle Room branding.
- Correct first-clock measurement, clock unplug/timeout handling and sample-rate/reset state clearing.
- Full stereo delay length through 192kHz, including the right channel's 5% offset.
- Finite, range-limited external input voltages.
- Standard Rack Makefile build using the committed Faust 2.85.9 header.
- Native zstd/tar packages for four platforms, verified binary architecture and ACID9-only manifest/assets.
- Two presets, a MIDI/audio example patch and an implementation-specific manual.

## Verification

- Local actual-module integration suite passed at 44.1, 48, 96 and 192kHz: gate/retrigger, knobs/CV, insert/send, stereo delay timing, sync ratios/timeout, sample-rate change, patch restore/reset and extreme inputs.
- Additional checks cover sub mode, ghost, feedback, delay time, slide, V/oct tracking and a 60-second feedback soak.
- Local 60-second soak took about 0.24 seconds of wall time on this Mac (about 0.4% of one real-time core in the isolated harness; not a general Rack CPU guarantee).
- Local Rack 2.6.6 extracted and loaded the mac-arm64 package. Window creation failed in the desktop environment before panel rendering; graphical smoke verification is handled separately by Linux CI.
- Geometry checks cover controls, labels, screws, indicator and reserved branding space.

## Publication sequence

1. Pass all four Build Plugin jobs and inspect the actual Rack screenshot/example-patch log.
2. Review the resulting panel and audio demo. Listening and real audio-device interaction are separate from automated DSP checks.
3. Tag the tested commit `v2.1.1` and publish its four verified packages and release notes.
4. Update existing VCV Library issue #877 with version, exact commit SHA and reduced module scope. Ask maintainers to reopen; do not open a duplicate plugin issue.
5. Once accepted, install the Library build and confirm its version and single-module browser entry.

The existing v2.1.0 draft/tag is not the release candidate and must not be reused.
